# Keerat Ghuman portfolio redesign

The hero sets Keerat's name across two lines over the supplied portrait. Barlow Condensed sets the display type. The dark palette uses warm ivory text and copper accents. The light palette uses brown ink on ivory. On phones, Work and Résumé appear before the portrait.

The contour canvas traces evenly spaced levels in one field. A gap around the portrait leaves room for the face. Slow drift and a fine pointer can move the contours. Reduced-motion visitors start with a still image, and the animation stops outside the viewport and in a hidden tab. The visitor can pause or play it from the hero.

The project index uses thin rules and gives Website Content Summarization a wide lead position. Each link points to its original article. With JavaScript and native dialog support, the reader moves that same article into the dialog. The URL identifies the active project. The history entry keeps track of which tile opened the reader so Close, Escape, and Back can return focus. Direct links return to their matching tile. Previous and Next replace the current project fragment.

Experience rows show the organization, dates, role, and a short description before opening. The expanded details give the work and its measured results where available. Education has its own section. The portrait, résumé, and Barlow Condensed remain local.

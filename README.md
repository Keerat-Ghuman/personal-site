# Keerat Ghuman's portfolio

Keerat’s portrait introduces a portfolio of three engineering projects. Use the project index or the previous and next controls to browse case studies. The summarization project includes a working example you can try with your own text. The experience section includes selected career highlights and a downloadable résumé.

## Preview

Open [dist/index.html](dist/index.html) in a browser. The site uses static HTML, CSS and JavaScript and needs no installation or build. If you prefer a local server, run `python3 -m http.server 4174 --bind 127.0.0.1 --directory dist` from this folder and visit [localhost:4174](http://127.0.0.1:4174).

## Review the preview

- Review the introduction and portrait at desktop and phone widths.
- Pause and resume the moving skills strip.
- Browse all three projects with the index and previous or next controls. Try the example text and your own text in the summarization demo.
- Review the experience highlights, contact links, and résumé visitors can download.

The release decision follows review of the local site. To update the text or links later, edit `dist/index.html`. The `dist/` directory contains the site files for a static host.
